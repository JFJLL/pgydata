# 02 — 导出年龄、性别和组合分布图

**What it delivers:** 用户可以独立选择年龄图、性别图或“性别分布+年龄分布”，普通/历史 Excel 都正确嵌入精修 PNG。

**Blocked by:** 01 — 导出精细的省份/城市地域图

**Acceptance criteria:**

- [ ] 年龄图使用 `382×372` 五档横条卡，固定 0–40% 标尺，静态默认态不包含 tooltip。
- [ ] 性别图使用 `379×383` 环形图、双侧引导线、两位小数比例和底部图例。
- [ ] 新增独立字段 `fansGenderAgeChart`，生成 `783×390` 双卡组合图；原年龄/性别字段继续独立工作。
- [ ] 组合字段进入当前版本的字段选择、预计耗时依赖、普通导出、历史导出、中文表头和 XLSX 图片关系；图片缺失时容错且单元格不泄漏本地路径。
- [ ] 人口分布、历史导出、XLSX 媒体关系及当前回归测试通过。

**Execution context:**

- 先复核 Ticket 01 已通过且工作区未被其他会话改写。
- 参考来源：参考包主渲染器的人口分布函数/dispatch、runtime patch 的任务映射和导出接线、frontend patch 的组合字段逻辑、集成与历史导出测试。
- 当前前端是 `1.2.0`：必须定位当前活跃资源和锚点，不能覆盖或启用参考包 `assets/1.1.13`。
- 目标所有权包括当前渲染器、runtime/frontend patch、导出表头/历史存储及相关测试；只修改人口图和组合字段所需区域。

**Evidence to return:** 三张 PNG 尺寸/哈希、字段在选择器与两条导出路径的证据、XLSX media/drawing 测试输出、回滚方法。
