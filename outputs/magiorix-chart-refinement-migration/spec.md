# Magiorix 作图精修迁移 Spec

## Problem

当前 `1.2.0` 项目仍使用较早的蒲公英导出图实现，而经理交付的 `1.1.13` 源码包包含更精细的地图、人口分布、趋势和博主概览图片。两个目录不是待合并的版本分支；如果整体复制或按版本合并，会回退当前项目已有功能，并覆盖用户尚未提交的工作。

## Desired Outcome

用户继续使用当前 `1.2.0` 项目和现有采集流程。选择相应导出字段后，普通导出、历史导出和 Excel 图片嵌入均使用精修后的图片；现有非作图功能、版本号、发布状态和用户工作区保持不变。

目标图片包括：

- 省份/城市地域分布图：真实中国省级地图、五级色阶、摘要、切换状态和七项排名。
- 年龄/性别图：五档年龄横条卡、带引导线的性别环形图，以及独立的“性别分布+年龄分布”组合图片字段。
- 粉丝趋势图：近 30 个有效日值、日期去重排序、自动纵轴、无圆形节点、平滑曲线穿过全部日值。
- 博主概览图：使用原始图标资源，动态安排昵称/账号后的图标，按健康风险显示正常报价或“暂停接单”，字体层级贴近参考图。

## Acceptance Scenarios

- 当用户分别选择省份图和城市图时，系统应生成不同状态的 `784×464` PNG，且两张图都同时拥有地图、图例、摘要和排名，不只显示通用柱状图。
- 当用户选择年龄、性别或组合图时，系统应生成对应原生尺寸的 PNG；组合字段必须进入字段选择、普通导出、历史导出和 Excel 嵌图，且不得在单元格泄漏本地文件路径。
- 当趋势接口包含逆序、重复日期或超过 30 条记录时，系统应按日期去重、升序并保留最近 30 日；曲线使用全部有效日值，静态导出不包含 tooltip 或悬停竖线。
- 当博主为风险状态时，图文和视频报价均显示“暂停接单”且隐藏报价图标；正常状态保持真实报价和原始报价图标。
- 当 Python 主渲染器不可用并走 SVG 回退时，用户看到的结构、数据口径和关键状态应与主渲染路径一致。
- 当本次迁移完成时，当前项目的非作图测试不得新增失败，版本仍由当前项目管理，不产生安装包、发布清单或服务器变更。

## Decisions

- 这是一项“能力摘取迁移”，不是 `1.1.13 → 1.2.0` 版本合并。
- 经理包只作为只读参考和资源来源；禁止整目录、整版本资源或整份大文件覆盖。
- 当前项目是唯一目标基线。遇到同一文件双方都有改动时，保留当前逻辑，只手工迁入与作图直接相关的最小代码段。
- 四类用户结果按顺序迁移，每完成一类就运行其专项测试，保持项目随时可回滚和定位。
- tooltip、hover 参考线等交互态不烘焙进静态 PNG。
- 不修改核心采集数据口径；只对图表需要的日期规范化、展示排序和图片字段接线做最小改动。
- 不从交付包复制旧版本号、发布 manifest、安装包或后端发布状态。

## Test Seam

最高测试接缝沿用项目的图表集成测试：向渲染入口输入固定 payload，检查字段路径、PNG 尺寸/签名/关键像素或 SVG 文本，并验证运行时补丁幂等。组合图还必须沿用历史导出和 XLSX media/drawing 关系测试。

每个纵向 Ticket 先运行相关专项测试；最终运行项目现有 static、unit、integration、smoke/build 和 verification contract。视觉质量以交付包中的参考/实现对比图为基准，但不得把参考截图直接嵌入输出。

## Out of Scope

- 不合并两个版本，不升级或降级版本号。
- 不整体替换前端资源、Electron 主进程、`app.asar` 或运行时目录。
- 不打 Windows 安装包，不发布，不部署服务器，不更新线上 manifest。
- 不清理当前工作区，不提交、不推送、不创建 PR。
- 不顺手重构采集、登录鉴权、后台或任务调度逻辑。

## Open Questions

无。执行时若当前工作区的用户改动与作图迁移发生同区域冲突，停止该处修改并报告具体冲突，不自行选择覆盖。
