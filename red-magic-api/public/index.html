使用说明

开始采集

按平台选择对应流程，先完成授权，再导入模板或手动输入链接开始采集。

1 授权蒲公英

进入软件后先完成蒲公英授权，授权状态显示为“已授权”后再创建采集任务。

2 导入采集对象

可以上传 Excel 文件批量导入，也可以在手动输入框中逐行输入小红书或蒲公英主页链接、24 位 UID。

3 开始采集

确认采集对象无误后点击开始采集，任务完成后在软件中查看并导出 Excel 结果。

1 进入抖音星图

在软件左侧选择“抖音”，打开“星图主页采集”，确认当前页面是星图主页采集入口。

2 完成星图授权

点击右上角“授权登录”，在巨量星图窗口中登录账号，回到软件后等待状态变为“已授权”。

3 导入星图链接

按模板上传 Excel，或在输入框中逐行粘贴星图主页、抖音主页等可识别链接后开始采集。

1 拖入应用程序

下载 magiorix.dmg 后双击打开，把 magiorix 拖到 Applications 文件夹完成安装。

2 打开启动台

安装完成后回到桌面，在程序坞中点击启动台图标，进入 Mac 应用列表。

3 启动 magiorix

在启动台中找到 magiorix，点击应用图标即可打开软件，之后也可以从“应用程序”中启动。
