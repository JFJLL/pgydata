使用说明

开始采集

登录后先完成蒲公英授权，再选择 Excel 文件上传或直接输入 UID 开始采集。

1 授权蒲公英

进入软件后先完成蒲公英授权，授权状态显示为“已授权”后再创建采集任务。

2 导入采集对象

可以上传 Excel 文件批量导入，也可以在手动输入框中逐行输入小红书或蒲公英主页链接、24 位 UID。

3 开始采集

确认采集对象无误后点击开始采集，任务完成后在软件中查看并导出 Excel 结果。
